# SAA-96 — Decision Log

Companion to [../saa-96-implementation-plan.md](../saa-96-implementation-plan.md). Every committed decision for Phase 2 (WebSocket presence + live board sync), with rationale, evidence (repo files/symbols + `node_modules/next/dist/docs/` citations), and rejected alternatives.

Status legend:
- **decided-by-evidence** — resolved from repo artifacts + Next 16 docs; no user input needed unless the team overrides on product grounds.
- **needs-user-input** — a genuine product/strategy choice surfaced in the plan's "Open questions".

| D5 | **Auth on the stream = better-auth session cookie via `requireApiUser()` + `resolveBoard` + private-board ownership check, before subscription.
